神经网络学习的整体流程
一个完整的神经网络实践流程，可以清晰地划分为训练和测试两个阶段，并遵循一个标准的步骤。首先，我们需要建立模型，即选择网络的结构、层数和每层的神经元数量。其次，我们要定义损失函数，常用的有均方误差和交叉熵损失函数等，用以量化模型预测与真实标签的差距。接着，我们通过参数学习（即梯度下降和反向传播算法）来优化模型参数，使得损失函数最小化。这三个步骤不断迭代，直到模型收敛，我们便得到了一个最优的映射函数 。

在训练阶段，我们将大量的训练数据（如图片和对应的数字标签）输入模型。数据经过模型各层的计算后，在输出层得到一个预测向量。接着，损失函数会计算该预测向量与一个代表真实标签的“目标向量”（例如，若图片是“1”，目标向量就是在  维度为1，其余维度为0的向量）之间的差距。参数学习算法随即根据这个损失来更新网络中所有的权重和偏置，让模型下次遇到相似输入时预测得更准确。

当模型在训练数据上的损失降得非常低且趋于稳定后，训练阶段结束。我们进入测试阶段，用模型从未见过的测试数据来检验其泛化能力。如果模型在测试集上也表现出高准确率，就说明它成功学习到了手写数字的本质特征，可以被部署到实际应用中。

建立模型：来自神经科学的灵感
当设计神经网络模型时，最直接的灵感来源是模拟人类大脑——自然界已知最高级的智能系统。神经科学的研究揭示，大脑中的神经元是一个多输入、单输出的信息处理单元，并具备以下四个关键特性：
1. 多输入单输出：一个神经元通过树突接收来自多个其他神经元的信号，经过细胞体处理后，通过轴突输出单一路信号。
2. 空间与时间整合能力：神经元可以将来自不同位置的输入信号进行空间整合，也可以将不同时刻的输入信号进行时间整合。
3. 兴奋性与抑制性输入：输入信号分为两种，有的让神经元更兴奋，有的则抑制其活动。
4. 阈值特性：只有当所有输入信号的总和超过一个特定阈值时，神经元才会被激活并产生输出信号，否则保持静默。

卷积神经网络
传统全连接网络的局限
传统的前馈神经网络在处理图像等高维数据时面临两个主要问题。
- 参数量爆炸：一张  的手写数字图片有  个像素点，若输入层即  个神经元，与一个有  个神经元的隐藏层全连接，仅这一层的权重参数就达到  个。对于更大的  图片，参数量将是天文数字，导致计算负担过重和严重的过拟合。
- 无法处理空间结构：网络要求将二维的图像矩阵拉平成一维的向量作为输入，这完全丢失了像素点之间的空间位置信息，而这些信息对于理解图像内容是至关重要的。

为了解决这些问题，卷积神经网络（CNN） 应运而生。CNN 通过引入三个核心特性，极大地减少了参数量，并能有效处理高维的二维、三维数据。

卷积神经网络三大特性
局部连接：在全连接网络中，每个隐藏层神经元都要连接输入图像的所有像素。但在CNN中，每个神经元只与输入的一个局部小区域（例如  的窗口）相连接，它每次只“看”图像的一小部分。我们不关心单个神经元观察区域以外的东西，因为可以通过滑动窗口的方式，让网络逐个区域地扫描，最终也能覆盖整张图像。
权重共享：当用同一个卷积核（即滑动窗口）去扫描图像的不同区域时，我们使用完全相同的权重参数。这意味着，无论一个特征（比如一个边缘）出现在图像的左上角还是右下角，用于检测它的“滤波器”的参数是完全一样的。这相比于全连接中需要有专属参数来连接不同位置，极大地减少了参数量。
下采样（池化）：在卷积层之后，通常会接一个池化层来执行下采样操作。例如，Max Pooling 将特征图划分为几个  的区域，并只保留每个区域中的最大值。这一过程会直接降低特征图的空间分辨率（例如高度和宽度都变为原来的 ）。这不仅进一步减少了后续层的计算量，还有一个重要的作用：同样是  的卷积核，在分辨率低的特征图上能“看到”原始图像中更大范围的区域，从而模拟了一种多尺度查看的效果。
通过这三种特性，CNN 成功地将处理图像所需的海量参数降低到一个可接受的范围，使得处理二维甚至三维的视觉数据成为可能。参数量不再是 O(\text{输入像素数} \times \text{神经元数})，而是被缩减为 O(\text{卷积核大小} \times \text{卷积核数量})。

Transformer基础
动机：捕获长距离依赖的挑战
在处理序列数据（如文本）时，一个核心问题是：如何发现并利用数据中任意两部分的关联性？ 对于一个句子，理解其含义常常需要建立相隔较远的词之间的依赖关系。
传统的卷积操作只在小窗口内计算关联性，要让图像中左上角和右下角的像素建立联系，需要堆叠很深的卷积和池化层，代价高昂。另一种方案是采用循环神经网络（RNN），它将序列按顺序一个个处理，把信息像接力棒一样传递下去。但这也存在问题：当两个词在序列中间隔太远时，传递的信息容易“遗忘”；且 RNN 的串行计算模式导致训练和推理速度很慢。

Transformer 的出发点，便是设计一种能够快速、并行地计算序列中任意两个词元（Token）间相关性的方法，以摆脱串行建模范式的束缚，高效地捕获长距离依赖。

3. 加权求和信息：词元  最终的输出 ，是所有其他词元的值向量  按照它们对  的注意力权重  进行的加权求和：。

这个过程就像做阅读理解：首先，我有一个问题（Q）；然后，我去所有段落中寻找与问题相关的线索（K），并得到一个相关度分数（Softmax后变成权重）；最后，我把线索对应段落的答案（V），按相关度权重组合起来，形成我自己的理解（）。由于 Transformer 的所有计算都是一系列的矩阵乘法，这使得它非常容易在 GPU 上实现高效的并行计算。

多头注意力与位置编码
多头注意力是对自注意力机制的进一步增强。它并非将  维的  整体做一次注意力计算，而是将它们切分成  组（例如 ，每组  维），每组称为一个“头”，让每组独立地进行自注意力计算。这样做的原因是，不同的“头”被期望去关注不同类型的关系，比如一个头关注语法搭配，另一个头关注指代关系等。这与 CNN 中使用多个卷积核提取多种特征的直觉是一致的。

由于自注意力机制在处理序列时是全局两两比较，它完全没有考虑词元在序列中的位置信息（“我”是第一个词还是第三个词，不影响计算）。为了不丢失语序信息，Transformer 在输入的词嵌入上额外叠加了位置编码，为每个位置生成一个固定或可学习的向量，使得最终输入的 Token 向量本身就 “烙印” 了其在序列中的位置。

与AI Agent协作画图的实践经验
本次课程的后半部分，一位同学分享了他与 AI 智能体（Agent）协作进行科研和项目绘图的实践经验，核心要点在于如何通过优化与模型的交互来有效控制产出。

协作画图的基本流程与核心理念
与 AI Agent 协作画图是一个人机协同的过程，它并非一次性的指令输出，而是一个反复迭代的交互循环。这个循环通常包括四个阶段：
1. 输入语义材料：用户提供指令、参考图、数据等，构建上下文。
2. Agent决策与制作：模型理解用户意图，调用绘图工具（如生成代码或调用生图模型）进行制作。
3. 预览与审查：Agent 生成初稿后，会进行自我审查，判断是否达到要求。部分现代模型已内嵌了对科研伦理、数据真实性等方面的核查。
4. 人参与反馈：用户对产出进行“验收”，指出需要修改的具体对象、属性和理由。Agent 据此进行修订，开启下一轮迭代。

在整个流程中，最关键的指导思想是：始终明确你的读者是谁，他们将在什么场景和时间约束下理解你试图传达的那个关系或结论。 所有的优化都应围绕这一主旨，否则容易在迭代中偏离方向。

定义输入的六大要素
为了得到一个高质量的图，向 Agent 下达的指令（Prompt）应尽可能地结构化和详尽。一个复杂的 Prompt 通常应包含以下六个方面的信息：
1. 读者与目标：明确说明图的受众和沟通目标。例如，“以同行能理解的视角，解释编码器如何向解码器提供条件信息”。
2. 语义不变量与事实：陈述图中不可更改的客观事实与关系，通常源于论文正文、公式或实验数据。例如，“Q来自解码器，K/V来自编码器”。
3. 抽象边界：规定图的表达范围和省略范围。例如，“总览展开一个完整层，用  表示堆叠”。
4. 布局与视觉编码：对视觉呈现方式进行约束。例如，“主轴统一；跨分支连接走独立通道；突出本页关注机制”。
5. 参考边界：明确所提供参考材料的用途。例如，“原图用于核对事实，风格参考只用于借鉴配色、线宽和留白”。
6. 交付与验收：指定输出的文件格式、可编辑性要求和审核要点。例如，“可编辑的SVG格式，并按实际尺寸审阅”。

构建上下文的原则与优先级
要给 AI 提供高质量的材料，并清晰地标明它们各自的角色，这意味着告诉模型每份材料是用来约束什么的。这对于控制产出结果的准确性和风格至关重要。输入材料依其重要性有一个清晰的优先级。
- 最高优先级：事实与数据。 这包括论文正文、公式、CSV数据表格、实验记录等。它们承载了不能有丝毫偏差的事实与计算关系。你的指令中必须写明“以指定章节为准”、“使用数据的哪一列、什么单位”，甚至指明“没有重复运行数据，所以不要添加误差棒”。这能让模型输出在科学上是严谨的。
- 中等优先级：已确认的结构。 这通常指你此前与 Agent 协作生成的、已经审阅通过的框架图或局部模块。你要求模型从明确的一个源文件版本继续修改，并声明“只改指定的对象，保持其他所有元素不变”，这可以保证迭代过程的高效和稳定。
- 较低优先级：纯粹的视觉偏好。 这主要指参考图或风格指南，它们用于借鉴配色、留白或线宽，而不是复制事实。指令中要写明“参考图只借配色与留白”，防止模型错误地将参考图中的信息也画入你的科学图表中。\n\n永远要让事实与数据的优先级高于已确认的结构和视觉偏好。

开启绘图工作的两种范式与候选探索
根据你自身思路的清晰程度，有两种方式可以开启与 Agent 的协作。
- 目标明确时：如果你对图的最终形态、关键关系和布局已胸有成竹，直接进入“细化规格”的模式。你应提供详细的结构描述、关系清单、草图或参考图，构建一个高度具体的 Prompt，快速地生成初版。
- 暂时没有思路时：如果你还不清楚如何呈现最好，可以先使用较为宽泛的任务描述，让 Agent 给出多个候选方案。你从这些候选方案中挑选方向，再进行迭代。

在利用候选探索创意时，一个核心策略是一次只改变一个维度。比如，你可以先固定统一的结构，让 Agent 只改变图的布局（如横向主轴、垂直泳道、总览加局部），比较不同阅读顺序带来的表达效果。选定布局后，再固定布局，去探索不同的视觉隐喻、颜色编码或信息密度。这样做能让各候选方案具有可比较的差异，帮助你做出清晰的设计决策。

局部修订、数据对齐与沉淀Skill
当需要修改时，给出一个“可验证的修订指令”比一句模糊的反馈有效得多。一个完整的修订指令应包含：从哪个版本的文件继续；只修改哪一个或哪几个明确的对象（如某个节点的颜色、某条边的走向）；明确指出需要保持不变的所有属性和结构（如双分支、坐标、字号）；并要求 Agent 在交付时提交变更清单，以检查没有引入新的错误。

对于统计图表，尤其需要根据原始数据来对齐细节。不能只说“画个漂亮的趋势图”，而必须指定：横轴纵轴各代表什么及其单位；数据的比较口径（例如是BLEU分数）；哪些值是并列的；在没有多次重复实验的情况下是否应该省略误差条。这确保了图的美观性不会以牺牲科学的准确性和可解释性为代价。

最后，可以将屡试不爽的工作流程沉淀为个人的skill。一套图往往会包含统一的视觉规则，如颜色编码、字体、节点尺寸等。将这些可复用的规则、检查清单和导出格式要求，通过 human-in-the-loop 的方式与 Agent 反复打磨，最终固化成专属于你的 skill。在后续的类似任务中，只需调用这个 skill，并提供新任务的事实性输入（如数据、论文正文），就可以复现出一致且专业的输出。
